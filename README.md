# Retirement-Planner-V2
A retirement planning simulator designed for international retirement.

Main features

- Multiple tax residencies
- Multiple living countries
- Multiple house ownership
- Pension modelling
- Irish property CGT
- Country cost database
- Property growth modelling
- Timeline based retirement planning

Countries currently planned

- UK
- Georgia
- Albania
- Bulgaria
- Cyprus
- Philippines
- Malaysia
- Thailand
- Paraguay
- Moldova

- Spain
